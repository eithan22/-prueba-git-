# Prueba Git 🔀

A **JavaScript practice project** used to learn and apply core **Git and GitHub** version control workflows. Demonstrates branching, committing, pushing, and collaborating via Git as part of the software development learning process.

---

## 📋 Description

This repository was created specifically to practice Git version control commands and workflows. It contains JavaScript code used as a vehicle for practicing common Git operations such as initializing repositories, creating branches, staging changes, committing, and pushing to GitHub.

---

## ✨ Git Concepts Practiced

- 📁 **git init** — Initialize a local repository
- ➕ **git add** — Stage files for commit
- 💾 **git commit** — Save changes with descriptive messages
- 🌿 **git branch** — Create and manage branches
- 🔀 **git merge** — Merge branches into main
- 🚀 **git push / pull** — Sync with remote repository
- 🔍 **git status / log** — Inspect repository state and history
